DEFECT #2: ASYNC METHODS WITHOUT AWAIT - cache.store() and cache.get()
================================================================================
Severity: CRITICAL
Category: Missing async/await syntax

Issue:
  README Example (Line 13-17):
  ```python
  cache = CacheManager()
  cache.store("users", "{'id': 1}")
  print(cache.get("users"))
  ```

Problem:
  - Both cache.store() and cache.get() are async coroutine functions
  - README shows calling them as if they were synchronous
  - Will return unawaited coroutine objects instead of actual results
  - Also, CacheManager requires cache_dir parameter but README omits it

Actual Implementation (datasync/cache.py):
  ```python
  async def store(self, key, value):
      await asyncio.sleep(0.05)
      ...

  async def get(self, key):
      ...
  ```

Error Behavior:
  - cache.store() returns: <coroutine object CacheManager.store at 0x...>
  - cache.get() returns: <coroutine object CacheManager.get at 0x...>
  - RuntimeWarning: coroutine was never awaited

Impact:
  - Example code runs but produces wrong results (coroutine objects)
  - Users cannot cache data correctly
  - Missing parameter causes TypeError if code is fixed

Solution:
  - Use async/await syntax: await cache.store(...) and await cache.get(...)
  - Add cache_dir parameter: cache = CacheManager("cache")
  - Wrap in async function or use asyncio.run()

DEFECT #3: ASYNC METHODS WITHOUT AWAIT - sync.sync_all()
================================================================================
Severity: CRITICAL
Category: Missing async/await syntax

Issue:
  README Example (Line 24-31):
  ```python
  sync = DataSync("https://api.example.com")
  result = sync.sync_all({
      "data/users": "output/users.json",
      "data/info": "output/info.json"
  })
  print(result)
  ```

Problem:
  - sync_all() is an async coroutine function
  - README shows calling it without await
  - Will return unawaited coroutine object instead of list of file paths
  - Expected output cannot be achieved with code as documented

Actual Implementation (datasync/core.py):
  ```python
  async def sync_all(self, mapping):
      results = []
      for endpoint, path in mapping.items():
          result = await self.sync_local(endpoint, path)
          results.append(result)
      return results
  ```

Error Behavior:
  - Returns: <coroutine object DataSync.sync_all at 0x...>
  - Expected output in README never prints
  - RuntimeWarning: coroutine was never awaited

Impact:
  - Example code cannot produce expected output
  - Users cannot sync multiple files correctly
  - Code will fail in production use

Solution:
  - Use async/await: result = await sync.sync_all(...)
  - Or use asyncio.run(): result = asyncio.run(sync.sync_all(...))
  - Wrap in async function
