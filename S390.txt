  - Error: TypeError: CacheManager.__init__() missing 1 required positional argument: 'cache_dir'
  - Reason: README calls `CacheManager()` without args; actual code requires `cache_dir`. Also `store` and `get` are async functions — they must be awaited.

- advanced_example (async usage)
  - Symptom: code returns a coroutine instead of list; runtime warning: coroutine never awaited.
  - Reason: README calls `sync.sync_all(...)` synchronously; `sync_all` is async and must be awaited.

- Environment variables (.env) claim mismatch
  - Symptom: README says you can set BASE_URL in .env and skip passing it manually.
  - Reason: The DataSync implementation does not read `.env` or environment variables. It requires `base_url` parameter explicitly.

- Key normalization note (behavior, not necessarily a bug)
  - DataSync stores cache keys using the passed endpoint string. If endpoint is `'/data/users'`, the key becomes `_data_users.cache` (leading underscore). Documented examples should use consistent key forms (e.g. include leading slash explicitly) or normalize keys in code.
